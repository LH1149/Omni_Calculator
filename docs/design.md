## 一、项目概述

UniCalc 是一个 Windows 桌面通用运算器，采用 **Python + tkinter + PyInstaller** 技术栈，打包为单文件 exe。视觉风格为 **iOS 玻璃风（方案A）**，无边框圆角窗口、半透明玻璃面板、可换肤背景。功能上支持多种运算模式的切换，初始包含 **数学计算器模式** 和 **汇率换算模式**，后续可插拔扩展更多模式。

## 二、技术栈

| 组件 | 说明 |
|---|---|
| Python 3.10+ | 运行时 |
| tkinter | GUI 框架（内置，无需额外安装） |
| Pillow (PIL) | 图像处理（圆角遮罩、玻璃覆盖层、图标生成） |
| PyInstaller | 打包为单文件 exe |
| tkinter-glass-ui skill | 开发时调用此 skill 辅助实现玻璃 UI 组件。用户指定路径 `~/.trae/skills/tkinter-glass-ui/SKILL.md`，当前文件尚不存在，开发前需用户创建。Fallback：viddownload 项目已有完整的 glass UI 实现代码（无边框窗口、透明色键、玻璃覆盖层预渲染、自绘圆角按钮等），可直接参考提取。 |

### 3.2 左侧栏（固定宽度 180px）

从上到下依次排列：

| 序号 | 控件 | 类型 | 说明 |
|---|---|---|---|
| 1 | 头像 | 圆形图片 | 84×84px，用户可自定义替换 |

**模式选择控件** 是核心交互入口：
- 显示为胶囊样式下拉框，当前选中模式名称 + 右侧下拉箭头
- 展开后列出所有可用模式：
  - **数学计算器** — 标准计算器运算
  - **汇率换算** — 多货币实时汇率换算
  - （后续可扩展：单位换算、日期计算、程序员模式等）

### 3.3 右侧主内容区

主内容区根据左侧选择的模式动态切换。

## 四、模式一：汇率换算模式

> 以下基于用户桌面手绘稿 `通用运算器.png` 的设计。

### 4.1 布局

右侧主内容区为 **5 行货币选择框**，垂直等距排列：

```
┌─ 右侧主内容区 ──────────────────────────┐
│                                         │
│  ◆ 人民币 CNY        [    输入金额    ]  │  ← 第1框：可输入
│                                         │
│  ◆ 马来西亚林吉特 MYR    123.45         │  ← 第2框：输出（只读）
│                                         │
│  ◆ 印尼盾 IDR          456,789          │  ← 第3框：输出（只读）
│                                         │
│  ◆ 新加坡元 SGD        78.90            │  ← 第4框：输出（只读）
│                                         │
│  ◆ 越南盾 VND          1,234,567        │  ← 第5框：输出（只读）
│                                         │
└─────────────────────────────────────────┘
```

### 4.2 货币选择框结构

每个框为一行，结构为：

```
[◆ 货币中文名称  货币代号]  [金额区域]
```

| 区域 | 说明 |
|---|---|
| ◆ 菱形符号 | 位于框最左侧，点击后弹出货币选择列表 |
| 货币中文名称 | 紧贴菱形右侧，如「人民币」「马来西亚林吉特」 |
| 货币代号 | 紧跟中文名称后，如「CNY」「MYR」 |
| 金额区域 | 右侧，第1框可编辑输入，其余4框只读展示 |

**货币显示格式**：`中文名称  货币代号`（空格分隔）
- 例：`人民币 CNY`
- 例：`马来西亚林吉特 MYR`
- 例：`印尼盾 IDR`
- 例：`新加坡元 SGD`
- 例：`越南盾 VND`

### 4.3 输入框 vs 输出框

| 属性 | 第1框（输入框） | 第2~5框（输出框） |
|---|---|---|
| 可编辑 | 是 | 否（仅展示） |
| 金额区域 | Entry 输入框，可输入数字 | Label 标签，显示计算结果 |
| 用途 | 输入待换算金额 | 实时显示其他货币换算结果 |
| 视觉区分 | 输入框有边框、白底、可聚焦 | 输出框无边框或浅色底，不可聚焦 |

### 4.4 默认货币配置

| 框序号 | 默认货币 | 货币代号 |
|---|---|---|
| 第1框（输入） | 人民币 | CNY |
| 第2框（输出） | 马来西亚林吉特 | MYR |
| 第3框（输出） | 印尼盾 | IDR |
| 第4框（输出） | 新加坡元 | SGD |
| 第5框（输出） | 越南盾 | VND |

### 4.5 菱形符号交互

- **样式**：实心粉色菱形（◆），与整体 iOS 玻璃风格一致
- **点击行为**：点击任意框的菱形 → 弹出**搜索弹窗**（输入关键词搜索货币中文名称或代号）
- **货币列表内容**：预置全量货币（中文名称 + 货币代号），支持搜索过滤
- **选择后**：该行的货币中文名称和代号更新，输出金额重新计算

### 4.6 汇率换算逻辑

- 用户在第1框输入金额 → 实时计算第2~5框对应货币的等值金额
- 汇率数据来源：**在线 API 获取**（需联网，开发时选定具体 API 并做容错处理）
- 计算方向：输入货币 → 4种输出货币
- 输出金额格式化：保留2位小数，千分位逗号分隔（越南盾等大数额可适当调整精度）

## 六、窗口与视觉规范

### 6.1 窗口属性

| 属性 | 值 | 说明 |
|---|---|---|
| 无边框 | 是 | `overrideredirect(True)` |
| 圆角半径 | 24px | 窗口外圆角 |
| 透明色键 | `#ff00fe` | 四角透明（`-transparentcolor`） |
| 标题栏高度 | 48px | 自定义拖动区域 |
| 任务栏图标 | 是 | 设置 `AppUserModelID` |
| 窗口阴影 | 是 | `DwmExtendFrameIntoClientArea` |
| 可调整大小 | 是 | 右下角拖拽热区 |
| 默认尺寸 | 约 560×620 | 可根据内容微调 |
| 最小尺寸 | 460×500 | 防止过小 |

### 6.2 iOS 玻璃配色

| 色彩变量 | 色值 | 用途 |
|---|---|---|
| GLASS_FILL | `rgba(255,255,255,148)` | 玻璃面板填充（半透明白） |
| GLASS_EDGE | `rgba(255,255,255,120)` | 玻璃面板顶部高光边 |
| TEXT_DARK | `#1d2230` | 主文字色 |
| TEXT_GREY | `#5c6478` | 次要文字色 |
| FIELD_BG | `#ffffff` | 输入框背景 |
| FIELD_BD | `#d3d8e2` | 输入框边框 |
| IOS_BLUE | `#0a84ff` | 聚焦/选中 |
| IOS_PINK | `#ff375f` | 菱形符号、关闭按钮 |

### 6.3 背景皮肤系统

- 背景图铺满整个窗口，玻璃面板覆盖其上
- 支持静态图片背景
- 皮肤配置存储在 exe 同目录 `skins/skin.json`
- 左侧栏「更换皮肤」按钮 → 选择图片 → 复制到 `skins/` → 更新配置
- 内置默认皮肤：`assets/skin.default.jpg`
